# Dynamische Homey-status — HISTORISCH / NIET ACTIVEREN

Deze instructie hoort bij de uitgefaseerde publieke GitHub Pages/Homey-statuspublicatie van augustus 2026. De vroegere `docs/data/homey-status.json` publicatie en de bijbehorende workflow zijn retired. Voer deze oude procedure niet opnieuw uit; stel geen `HOMEY_TOKEN` of `GH_Status_Token` in om een publieke GitHub-statusfeed te herstellen.

De actuele EMS-status loopt via Homey→Pi-ingress en de private Pi Web Data API. Zie [Current EMS State](docs/architecture/CURRENT-EMS-STATE.md) en [diagnostische bronhiërarchie](docs/architecture/diagnostic-source-of-truth.md).
